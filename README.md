# 2000Lesano

A personal homepage made for the old web. Built with simple HTML and designed to remain usable on older browsers, including Internet Explorer 5.5/6 and classic systems.

## Demo

- http://lesano.rf.gd
- https://lesano.rf.gd
- http://lesano.optikl.ink

## Why?

I enjoy retro computers and wanted a personal website that feels like the early 2000s while being genuinely lightweight and compatible with older browsers.

## Design goals

- HTML 4.01 Transitional
- Simple tables and classic HTML presentation
- No JavaScript required
- No modern CSS layout dependencies
- Small images and old-school animated GIFs
- Designed around an 800x600 desktop experience

## Pages

- `index.html` - Homepage
- `projects.html` - Project archive
- `lab.html` - Experiments
- `log.html` - System log
- `about.html` - About the author
- `secret.html` - Hidden page

## Tested systems

- Windows 98 (Internet Explorer 5.5)
- Windows NT 4.0 (Internet Explorer 6)
- Windows 2000 (Internet Explorer 6)
- IBM OS/2 Warp 4.5 (Netscape Navigator)

Compatibility can vary by hosting provider, browser configuration and TLS support. The site itself avoids modern browser features where possible.
